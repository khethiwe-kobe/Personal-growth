Two honest caveats

Beverley at R9,000 is the only headline price close to yours, and it is a kilometre nearer CRC. But no listing in this table except SoHo states whether levies are included — and at SoHo those run R1,290–R1,400. If Beverley bills them on top it lands around R10,300 against your R8,800. Worth one call if you want to be certain, though the amenity gap is wide.

Rosewood Terraces at R8,200 is the cheapest two-bed anywhere here — but it has one bathroom, and you have set two as a requirement.
